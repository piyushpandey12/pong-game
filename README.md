# Pong — a little browser game

A responsive, single-player Pong arcade built with HTML, CSS, and JavaScript. No installation or build step is required: serve the project directory with any static web server.

Choose Easy, Normal, or Hard and a winning score of 5, 7, or 11 before starting a match. Move with the arrow keys, W/S, a mouse, or touch and drag. Press Enter to start, Space to pause or resume, and R to reset the match. The toolbar also provides pause, reset, and fullscreen controls where supported.

Matches include a serve countdown, a result screen, optional synthesized arcade sounds, and live match statistics. Switching tabs or leaving the window automatically pauses play. Settings are locked during an active match; reset the match to change them. Scores and statistics are temporary for the current match and are not saved. Sound is off by default.
